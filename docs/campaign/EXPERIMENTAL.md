## Isolation and enable/disable

No flag file means no experimental tool at all. A full-profile MCP session advertises only explicitly enabled actions from `/data/anylist-experimental.json`:

```json
{"item_prices":false,"list_folders":false}
```

Enable a single boolean only after reviewing the receipt. This non-secret box-side config is intentionally uncommitted. The restricted Gina profile never registers experimental tools. Every call rechecks its flag, so disabling takes effect even for an existing MCP session; reopen the session to refresh discovery. Delete the file to disable all. Each feature can be disabled without a stable MCP/GPT rollback. GPT OpenAPI is generated exclusively from the stable registry and remains30 operations.

The extension uses the pinned library's authenticated read transport and its protobuf decoder, then validates/projects explicit response fields. It never takes an endpoint, RPC name or arbitrary schema from the caller. It does not modify raw snapshots or write protocol data. Experimental schema drift returns EXPERIMENTAL_SCHEMA_CHANGED; missing completeness returns EXPERIMENTAL_INCOMPLETE; revoked flags return EXPERIMENTAL_DISABLED. Stable shopping/recipe operations neither load experimental data nor depend on successful experimental parsing.

Prices require an exact list ID/name, optionally item ID/name, with limit1..100/default50 and explicit offset/hasMore/total. Without item selector only priced items are returned. A price record's amount is not automatically a currency-normalized unit cost. Folders accept exact optional folder ID/name and explicit paging; their sourceComplete is distinct from a paginated result's hasMore. No folder mutation is exposed.

Qualification: `node scripts/experimental-read-qualification.js` inside the deployed container. It refuses pre-existing experiment settings, enables just these reads for a temporary full-profile MCP session, checks actual responses and per-feature revocation, removes flags and deletes the temporary bearer in finally. It never mutates provider data. Keep ordinary stable regression checks alongside it.
